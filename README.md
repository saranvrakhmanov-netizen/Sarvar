# ХимЛаб: лаборатория открытий

Обучающее Android-приложение для ребёнка 9 лет: виртуальные химические эксперименты, карточки с фактами, мини-уроки и игровые награды.
Рассчитано на планшет **Redmi Pad 2**, работает **без интернета**, на русском языке.

> **Важно про честность проверки.** Проект написан и проверен статически (структура, XML, YAML, баланс скобок), но в среде, где он создавался, не было Gradle, Android SDK и интернета.
> Поэтому **сборка APK и запуск на планшете здесь не выполнялись**. Первая сборка в GitHub Actions — это настоящая проверка. Если она упадёт, откройте лог шага «Собрать APK»: ошибку компиляции обычно легко исправить по тексту сообщения.

## Что умеет приложение

| Раздел | Что внутри |
|---|---|
| 🧪 Лаборатория | 8 веществ (вода, краситель, масло, соль, сахар, сода, уксус, песок), 28 смешиваний. Анимированная колба, результат, объяснение, реакция Пузырька, подсказки |
| 📋 Опыты-задания | «Цветная вода», «Вода и масло», «Вода и соль», «Сода и уксус»: задание, вопрос и 1–3 звезды |
| 📖 Азбука химии | Атомы и элементы, вещества, смеси, химическая реакция + 2 викторины |
| 💡 Интересные факты | 13 карточек: вода, лёд, кислород, воздух, углерод, железо, соль, пузырьки газа, углекислый газ, водород, золото, сахар, атомы |
| 🏅 Достижения | 12 наград и «Карта открытий»: что смешалось, что разделилось на слои, где была реакция |
| 👨‍👩‍👧 Для взрослых | О безопасности, научных упрощениях, приватности; сброс прогресса |

**Безопасность:** все смешивания только виртуальные. Приложение не предлагает ребёнку работать с реальными веществами, не называет бытовые вещества полностью безопасными и напоминает, что настоящие опыты — только со взрослым.

**Приватность:** нет рекламы, покупок, ссылок наружу и регистрации. В манифесте **нет разрешения INTERNET**. Прогресс хранится только на устройстве.

## Как получить APK через GitHub

### 1. Загрузите проект в GitHub

1. Создайте аккаунт на github.com и новый репозиторий (**New repository**), например `himlab`. Можно сделать его приватным.
2. Распакуйте архив проекта. В папке должны лежать `app/`, `keystore/`, `.github/`, `build.gradle.kts`, `settings.gradle.kts` и другие файлы.
3. Загрузите **все** файлы, включая скрытые папки `.github` и `.gitignore`. Надёжнее всего через командную строку:

```bash
cd HimLab
git init
git add .
git commit -m "ХимЛаб: первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/himlab.git
git push -u origin main
```

Либо через GitHub Desktop. Если загружаете через сайт (Add file → Upload files), проверьте после загрузки, что в репозитории есть папка `.github/workflows` с файлом `build-apk.yml`: некоторые системы пропускают скрытые папки при перетаскивании.

### 2. Запустите сборку вручную

1. Откройте репозиторий → вкладка **Actions**. Если GitHub просит включить Actions, согласитесь.
2. Слева выберите **«Сборка APK»** → кнопка **Run workflow** → **Run workflow**.
3. Подождите 5–10 минут (первая сборка дольше). Зелёная галочка означает успех.

### 3. Скачайте APK

1. Откройте завершённый запуск (клик по его названию).
2. Внизу страницы, в разделе **Artifacts**, нажмите **HimLab-APK**. Скачается ZIP-файл.
3. Распакуйте ZIP: внутри лежит `HimLab-1.0.N.apk` (N — номер запуска). Артефакт хранится 90 дней.

### 4. Сборка при публикации Release

1. В репозитории: **Releases** → **Draft a new release**.
2. В поле Tag введите, например, `v1.0.0` и выберите **Create new tag**, заполните название и нажмите **Publish release**.
3. Workflow запустится сам. Через несколько минут файл `HimLab-1.0.0.apk` появится в списке Assets этого релиза, и его можно скачать прямо оттуда, без ZIP.

## Как установить на Redmi Pad 2

1. Скачайте APK на планшет (откройте релиз в браузере планшета) или перенесите файл с компьютера по USB или через облако. Если скачали ZIP, распакуйте его в приложении «Файлы».
2. Откройте APK в «Файлах» или «Загрузках».
3. Если система скажет, что установка из этого источника запрещена, нажмите **Настройки** и разрешите установку приложений для этого приложения (браузера или «Файлов»). Точные названия пунктов зависят от версии HyperOS/MIUI.
4. Нажмите **Установить**. Если появится предупреждение защиты (Play Protect или проверка безопасности Xiaomi), выберите вариант установить всё равно: приложение не из магазина, но собрано из вашего исходного кода.
5. Откройте «ХимЛаб». Интернет больше не нужен.

Обновление: новую сборку можно ставить поверх старой, прогресс сохранится, потому что все APK подписаны одним и тем же ключом (`keystore/himlab-family.keystore`), а номер версии растёт с каждым запуском.

## Подпись APK

Чтобы обновления ставились поверх старых, проект подписывается постоянным ключом из папки `keystore/` (пароль `himlab123`, алиас `himlab`). Этот ключ лежит в открытом виде в репозитории, поэтому подходит **для личной установки в семье**. Для публикации в магазинах приложений создайте собственный секретный ключ и храните его в GitHub Secrets.

## Как менять содержимое

- Тексты результатов смешиваний, факты, вопросы викторин и уроки находятся в `app/src/main/java/ru/himlab/app/Data.kt`.
- Достижения: `AppState.kt`.
- Название под иконкой: `app/src/main/res/values/strings.xml` (если полное название обрезается на рабочем столе, замените на «ХимЛаб»).
